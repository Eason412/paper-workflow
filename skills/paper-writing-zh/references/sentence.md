# 句子与搭配

## 一、句子

句子难读通常出在四处：一句里装了几个判断，主干不成立，修饰语和中心词不配，中间没有停顿。下面按这个顺序给判断方法。每条的“不必改”是边界，不越过它去改没毛病的句子。

例句只示范句法，取自不同学科。改稿时不沿用例句的措辞。

### 1 长句、碎句和节奏

#### 长短由内容定

句子多长不设要求。一句装一个判断，连同它离不开的条件或原因，写完是多长就是多长。

不按字数拆句或凑句。给句子定一个字数范围，写出来的句子会全部挤进这个范围，长的被硬拆，短的被硬凑，整段一个节拍。

句子难读有三个具体原因，改的时候找原因，不数字数：一句里装了几个判断；主语和谓语之间隔着很长的修饰语；逗号落在不能换气的地方。

#### 长句怎么拆

读着憋气的句子多半是下面三种结构：

- “某某实验表明，”后面拖一长串：工况、现象、转折、原因、结果都塞在“表明”的宾语里，读者要一口气读到句号。
- 冒号后面跟一串分号，把几篇文献或几件事绑成一句。见第 6 节。
- “虽然……但……然而……却……”连环转折，读者每半句拐一次弯。见 [段落](paragraph.md) 的连接词一节。

拆法是找出句子里的判断，一个判断一句。条件、原因和引用编号跟着自己的判断走。

改前：台架实验表明，在低速至中速区间内系统的跟踪误差随转速上升仅小幅增加，而一旦跨过临界转速进入高速区间，由于采样延迟来不及补偿相位偏移，加之谐波干扰显著增强，跟踪精度虽在稳态下尚可维持，但动态超调量却大幅上升。

改后：台架实验表明，在低速至中速区间，系统的跟踪误差随转速上升只有小幅增加。转速越过临界值后，采样延迟造成的相位偏移得不到补偿，谐波干扰也显著增强。此时稳态精度尚能维持，动态超调量则大幅上升。

改前一句有三个判断：低中速时误差变化小；高速区出现两个不利因素；结果是稳态尚可而超调变大。改后每句一个，两个原因都留着。

不必改：试件在 800 ℃ 下保温 2 h 后随炉冷却至室温，再以 0.5 mm/min 的速率加载至破坏。这句不短，但只讲一个流程，每个逗号处都能停。拆开反而要重复主语。

#### 碎句怎么合

改前：高速区相位偏移显著增大。须改用自适应前馈补偿。这样才能消除采样延迟的影响。该补偿方法还需经台架实验验证。

改后：高速区相位偏移显著增大，须改用自适应前馈补偿才能消除采样延迟的影响。这种补偿方法还需经台架实验验证。

读着碎的句子多半是下面三种结构，都并回上一句：

- 把上一句的目的、结果或条件拆出来，用“这样才能”“从而”“由此”起句。
- 连续用“这种”“这类”“该”“其”起句，每句只往前挪半步。去掉句首的指代词，这个句子就不知所云。
- 把同一个对象的优点和局限拆成“……。但它……。”两句。

合并碎句时，一句之内最多换两次主语。机理或原因本身已经包含成对分句（如“前者……，后者……”）时，由此带来的性能变化另起一句，不把三层对象硬焊成一句。

不必改：指代词后面跟着名词、句子自身是一个完整判断时，属于正常衔接，如上面的“这种补偿方法还需经台架实验验证”。

#### 节奏

同一条因果链上的短句并成一句，独立的判断留成短句。这样长句和短句自然错开，不需要刻意凑长度。

改前（七句一个长度、一个句式）：轴承早期故障的冲击成分十分微弱。背景噪声会将其完全淹没。包络谱中难以识别故障特征频率。共振解调方法依赖滤波频带的选取。频带选取不当会导致解调失败。谱峭度方法可以自动确定最优频带。但它对随机脉冲干扰比较敏感。

改后（前两句各讲一条因果链，第三句把同一个方法的优点和局限放在一起）：轴承早期故障的冲击成分十分微弱，会被背景噪声完全淹没，包络谱中难以识别故障特征频率。共振解调方法依赖滤波频带的选取，频带选取不当会导致解调失败。谱峭度方法可以自动确定最优频带，但对随机脉冲干扰比较敏感。

不必改：并列的几条结论、操作步骤，本来就该用长度相近的句子。

### 2 主干检查

把定语、状语、补语都拿掉，只留主语、谓语、宾语的中心词，读这个短句。常见毛病如下表。

| 类型 | 改前 | 毛病 | 改后 |
| --- | --- | --- | --- |
| 缺主语 | 通过对比不同转速下的电流波形，表明所提模型精度较高。 | 主语被“通过”吞掉，“表明”没有主语 | 不同转速下的电流波形对比表明，所提模型精度较高。 |
| 缺主语 | 在引入前馈补偿后，使系统的相位滞后明显减小。 | “在……后”加“使”，句子没有主语 | 引入前馈补偿后，系统的相位滞后明显减小。 |
| 缺谓语或宾语中心词 | 该方法擅长多变量耦合问题。本章建立了考虑铁心饱和的永磁同步电机。 | “擅长”后面缺动词；“建立”的宾语缺“模型” | 该方法擅长求解多变量耦合问题。本章建立了考虑铁心饱和的永磁同步电机模型。 |
| 搭配不当（一动多宾） | 新策略提高了系统的精度和响应时间。 | “提高”配不上“响应时间” | 新策略提高了系统的精度，缩短了响应时间。 |
| 搭配不当（一主多谓） | 已有研究揭示了裂纹控制机理，并通过化学改性改善了界面耗能。 | “研究”能配“揭示”，配不上“改善耗能” | 已有研究揭示了裂纹控制机理，并证实化学改性能够改善界面耗能。 |
| 范围词错当主语 | 细观层面揭示了纤维分布的作用，本构层面提出了标定流程。 | 删掉介词拿方位/范围状语硬当动作主语 | 已有工作从细观尺度揭示了纤维分布的作用；在本构建模方面，研究者提出了标定流程。 |
| 搭配不当 | 温度是材料强度下降的重要原因。 | 主语和宾语不对应：“温度”是因素，“温度升高”才是原因 | 温度升高是材料强度下降的重要原因。 |
| 句式杂糅 | 误差增大的原因是由于采样延迟造成的。 | “原因是……”和“是由于……造成的”两种说法套在一起 | 误差增大的原因是采样延迟。 |
| 暗换主语 | 文献 [5] 采用声发射监测裂纹扩展，但难以定位内部缺陷。 | 后半句的主语已经从“文献”换成“声发射”，却没写出来 | 文献 [5] 采用声发射监测裂纹扩展，但这种方法难以定位内部缺陷。 |
| 指代不明 | 模型 A 的误差大于模型 B，因为它忽略了饱和效应。 | “它”可以指 A 也可以指 B | 模型 A 的误差大于模型 B，因为模型 A 忽略了饱和效应。 |
| 比较的两头不同类 | 所提策略的电流误差是传统开环控制的 25%。 | 拿“误差”去比“控制” | 所提策略的电流误差是传统开环控制下误差的 25%。 |
| 一面对两面 | 能否准确辨识参数，是模型达到高精度的前提。 | 前面说“能否”两面，后面只说一面 | 准确辨识参数是模型达到高精度的前提。 |
| 关联词位置 | 不仅该方法提高了精度，而且缩短了计算时间。 | 两个分句同一个主语，关联词应在主语后面 | 该方法不仅提高了精度，而且缩短了计算时间。 |
| 并列不当 | 实验平台包括传感器、数据采集卡和测量设备。 | “测量设备”包含前两项，不能并列 | 实验平台包括传感器、数据采集卡等测量设备。 |

### 3 搭配和平衡

- **共用成分逐一配。** 一个主语带几个谓语、一个动词带几个宾语、一个形容词修饰几个名词时，把每一对单独读一遍。“提高了精度、效率和计算时间”里第三对不成立；“已有研究揭示了……并通过改性改善了……”里第二对不成立。
- **分类词贴合对象的真实性质。** 不把“层面、维度、视角、体系”当成万能筐：空间大小用“尺度”（微观/细观尺度），结构分级用“层面”（材料层面、构件层面），外部条件用“工况/环境”（高温耦合工况），理论与方法用“方面”（本构建模方面），两类荷载就直接叫“两类荷载”（不叫“两个维度”）。不同性质的几项并列时（如细观增韧、动力损伤与本构模型），后面不硬加“三个层面”统括。
- **并列项对称。** 并列的几项用同一种结构：都是名词短语，或都是主谓短语。“该方法计算量小、高精度、抗噪声”三项三种结构，改为“该方法计算量小、精度高、抗噪声能力强”。
- **按量的性质选词。** 名词属于哪一类量，就用哪一对形容词和动词，见后面的搭配表。
- **“是”字句两头对得上。** “A 是 B 的前提、基础、关键、原因”里，A 和 B 要是同一类东西：动作对动作，性质对性质。“参数辨识的研究是提高精度的关键”改为“准确辨识参数是提高精度的关键”。
- **句首不叠介词短语。** “针对……，通过……予以抑制”这种句子没有主语，宾语也悬着。能写成“谁、做什么、对什么”就直接写：“注入三次谐波电压可以抑制高速区的电流谐波”。
- **句子不要头重脚轻。** 主语或定语很长、谓语只有几个字，读者要等很久才知道在说什么。

  改前：考虑铁心饱和、交叉耦合和空间谐波影响的永磁同步电机高保真模型的建立是本章的重点。

  改后：本章的重点是建立永磁同步电机的高保真模型，模型考虑铁心饱和、交叉耦合和空间谐波的影响。

### 4 主语什么时候写，什么时候省

- 逗号或句号后面换了陈述对象，必须写出新主语。
- 连续几个分句说的是同一个对象，后面的主语可以省，不模仿英文连用“他们……他们……”“它……它……”。例如“赵继之等 [32] 开展了循环加载试验，分析了纤维掺量的影响，建立了滞回本构模型”，直接承前省主语，不拆成三句“赵继之等……他们……他们……”。
- 介词短语不能当主语。“通过……”“经过……”“在……下”“随着……”开头的句子，检查后面有没有真正的主语。
- 摘要里省略“本文”的写法是体例，不算缺主语，见 [首尾部件与论文体裁](structure.md)。
- 不为了凑主语硬加“研究”“文中”“笔者”。谁做的不重要时，让研究对象做主语：把“研究发现界面滑移决定了裂后韧性”写成“界面滑移决定了裂后韧性”。

### 5 “的”、“被”和“进行”

- **“的”字链。** 一个名词前面有三个以上“的”，或者定语长到读者迟迟等不到中心词，改变结构，不是简单删“的”。“一种适用于宽转速范围的考虑饱和效应的电机的模型”改为“一种考虑饱和效应的电机模型，适用于宽转速范围”。
- **“进行”“加以”“予以”加动词。** “对参数进行了辨识”直接写“辨识了参数”。不必改：后面是带数量的名词，如“进行了三组对比试验”。
- **“被”字句。** 做事的人明确、改成主动更顺时改。不必改：做事的人不重要或未知，如“样本已被污染”。
- **名词空转。** “实现了精度的提升”写成“提高了精度”；“具有结构简单的特点”写成“结构简单”。

### 6 标点

标点有层级：顿号分并列的词语，逗号分分句，分号分并列的几组分句，句号结束一个判断。按 GB/T 15834—2011。

- **分号**用在三处：成对的并列分句内部已经有逗号；分条列举的短项之间；“式中”各项之间。
- 列举的每一项自己能成句时，各项用句号分开。“误差较大有两个原因：一是……，……；二是……，……”这种写法，改成“误差较大有两个原因”先成一句，“一是……”“二是……”再各成一句。
- 不用分号把几篇文献或几个独立的判断连成一句。“文献 [3] 指出……；文献 [4] 引入……；文献 [5] 采用……”这种写法，改成每篇文献各成一句，局限相同的合起来说一次。
- **冒号**提起下文，一直管到句号。“表明”“指出”后面的内容如果不是管到句末，用逗号。一句里不套两个冒号。
- 一句话用了冒号、后面又跟两三个分号，等于把一段话绑成一句。拆成几句，每句一个判断。
- 冒号和分号用对了就留着，改稿时不为了减少它们去动没毛病的句子。拿不准时把它换成句号读一遍：换了以后两句各自站得住、意思没少，就用句号；换了以后一对并列或对比被拆散，或者总起的话管不住后面的内容，就留着。

  该留的冒号：电感辨识方法分为两类：基于电压方程的方法和基于阻抗模型的方法。冒号后面是总起所说的两类，一直管到句号。

  该留的分号：电感的扰动主要影响高频特性，扰动越大，动态响应的模拟精度越低；电阻的扰动主要影响低频特性，失配越大，稳态误差越大。两个分句是一对对比，合起来才是一个判断，各自内部又有逗号。

  该留的分号：式中，$L_d$、$L_q$ 为 d、q 轴电感；$\psi_\mathrm{f}$ 为永磁体磁链；$\omega_\mathrm{e}$ 为电角速度。

  该改的分号：文献 [3] 提出了带宽匹配条件；文献 [4] 引入了电压前馈。两篇文献各说各的，换成句号什么也不少。

  该改的分号：如图 2(a) 所示，在低速区误差平缓增长；跨过阈值进入高速区后误差陡增。前半句带整段共用的图表引出语，两句又是一静一动的阶段推进，用句号断开。
- **括号**只放短注：缩略语全称、单位换算、编号。能成句的补充说明另起一句。
- **顿号**只分并列的词和短语。并列项里已经有顿号时，上一层用逗号。
- 主语长到中途要换气时，先把主语里的修饰语挪到后面，不靠在主语和谓语之间加逗号来解决。

### 7 套话和翻译腔

下面这些出现时，看它有没有提供信息；没有就删或改成具体内容。

- “具有重要意义”“起着至关重要的作用”：写出后果或用途。
- “显著”“有效”“大幅”“明显”：后面要跟数据或比较对象。
- “不仅……更是……”“不是……而是……”：两半都有信息才留。
- “随着……的发展”“在……的背景下”：背景没有独立信息就删。
- “值得注意的是”“综上所述”“总的来说”：多数可以直接删。
- 四字词连用，如“高效精准、稳定可靠”：换成能检查的事实。
- “在……层面 / 从……维度 / 在……框架下”连排贴标签：按对象真实性质换回“尺度、工况、方面”，或直接让研究对象出场。

不必改：有数据支撑的“显著提高了 12%”；确实有先后顺序的“首先、其次”；小节末尾真正归纳了共性的“综上”。

### 8 专业术语与晦涩词

读者觉得晦涩的词分两类，处理相反：换成常规词后物理边界没变宽、没失真的，属于英文硬译或包装壳（如“界面调制手段”“跨维耦合赋能”），直接换回通行词（“表面化学改性”）；一换就损失物理精度的（如“变形局部化”“穿晶扩展”“Lode 角”“相场”），属于不可替代的真术语，原词保留。

真术语首次出场时，用下面四条让大同行也能顺畅读懂：

- **先演物理画面，再收成术语。** 前句或前半句先写具体动作和状态，后文或表内再凝练成术语。例如先写“高速加载使微裂纹来不及沿薄弱界面绕行，被迫直接穿过高强基体扩展”，再收束为“微裂纹穿晶扩展”；先写“变形集中于单条主裂缝，其余区域弹性卸载”，再点出“这一变形局部化特征”。
- **只点功能分工，不背教科书定义。** 借用跨小方向的概念时，用半句话交代它在这里解决什么问题。例如“未引入 Lode 角区分拉、压子午线，因此难以模拟拉伸主导的背面层裂”；“相场模型用光滑的标量场代替离散裂纹面，无需预设路径即可追踪裂纹分叉”。
- **控制单句术语密度。** 一句话只让读者消化一个陌生概念，不把三四个硬核词挤进同一个长定语（如“基于非局部正则化相场变分格式的各向异性率相关本构”）。
- **一词到底。** 首次出场铺垫清楚后，后文每次提到都原字复现，不为了修辞变化换同义说法。

## 二、搭配表

搭配出错多半是因为没看清名词属于哪一类。先按本部分第 1 节确定名词的类别，再选形容词和动词。表里列的是工科论文的常用搭配，学科有固定说法时以学科习惯为准。

### 1 按量的性质选词

| 名词说的是 | 形容词 | 变化用的动词 | 常见名词 |
| --- | --- | --- | --- |
| 高低 | 高、低 | 提高、降低；升高、下降 | 精度、强度、效率、温度、频率、电压、转速、水平、分辨率 |
| 大小 | 大、小 | 增大、减小 | 误差、偏差、幅值、电流、应力、位移、刚度、损耗、脉动 |
| 强弱 | 强、弱 | 增强、削弱 | 能力、鲁棒性、相关性、干扰、磁场、效应、耦合 |
| 快慢 | 快、慢 | 加快、减慢 | 速度、响应、收敛 |
| 长短 | 长、短 | 延长、缩短 | 时间、寿命、周期、距离 |
| 宽窄 | 宽、窄 | 拓宽、收窄 | 范围、频带、带宽 |
| 多少 | 多、少 | 增加、减少 | 数量、次数、样本、用量 |
| 好坏 | 好、差；优、劣 | 改善、恶化 | 性能、效果、一致性、条件、工况 |

用法：改句子前先问这个名词用哪一对形容词。“误差”分大小，所以是“误差较大”“减小误差”，不是“误差较高”“提高误差”。“响应时间”分长短，所以是“缩短响应时间”，不是“降低响应时间”。

表里列的是首选的搭配，不是唯一正确的搭配。“提高鲁棒性”“提高动态响应”这类学科里通行的说法不算错，自己写的时候可以用，改别人的稿时不动。要改的是确实配不上的，如“提高响应时间”“误差远低于传统控制”。

### 2 动词和宾语

| 宾语 | 常用动词 | 容易错配 |
| --- | --- | --- |
| 方法、模型、算法、策略、假设 | 提出、建立（模型）、设计（算法、控制器）、改进、验证 | 揭示方法 |
| 规律、机理、机制、原因 | 揭示、阐明、分析、归纳（规律） | 提出规律、建立机理 |
| 试验、实验、仿真、研究 | 开展、进行、完成 | 做研究（口语） |
| 参数 | 辨识、标定、测定、整定（控制器参数）、选取 | 提高参数 |
| 问题 | 解决、存在、出现 | 改善问题、克服问题 |
| 缺陷、不足、困难 | 克服、弥补（不足）、消除（缺陷） | 解决不足 |
| 要求、需求、条件 | 满足 | 达到需求 |
| 目标、指标、水平 | 达到 | 满足水平 |
| 功能、目的 | 实现 | 实现问题 |
| 作用 | 发挥、起到 | 取得作用 |
| 效果 | 取得、收到 | 起到效果 |
| 影响 | 产生、造成、减小、消除 | 提高影响 |
| 趋势 | 呈现、呈……趋势 | 趋势增大 |
| 损伤、退化、磨损 | 加剧、减缓、抑制、累积 | 提高损伤 |
| 振动、脉动、谐波、噪声 | 抑制、削弱、滤除（谐波、噪声） | 改善振动 |
| 特征 | 提取、识别 | 揭示特征频率 |
| 假设 | 提出、满足、放宽；假设成立、不再成立 | 打破假设 |
| 滞后、偏移、漂移、畸变 | 补偿、校正、抑制、减小 | 改善滞后 |
| 范围、边界 | 界定、扩大、缩小 | 提高范围 |

### 3 主语和谓语

- 现象和状态做主语：出现、发生、消失、加剧、减弱。“裂纹萌生、扩展、贯通”“界面脱粘、滑移”。
- 数值做主语：增大、减小、升高、下降、保持不变、趋于稳定。
- 方法和模型做主语：能够描述、可以预测、适用于、依赖于。模型不“认为”“发现”，这两个动词的主语是人。
- 图、表、结果做主语：表明、说明、显示、给出。“图 3 给出了……”“结果表明……”。
- 收敛、发散、失稳说的是对象自身的状态，后面不带宾语：写“误差收敛”“系统失稳”，不写“收敛了误差”。

### 4 定语和中心词

- 表示程度的形容词按第 1 节的类别选：较高的精度，较大的误差，较强的鲁棒性，较快的响应，较长的寿命，较宽的频带，较好的一致性。
- “显著”修饰变化和差别：显著的差异、显著提高。不说“显著的精度”。
- “严重”修饰不利的事：严重的损伤、严重失真。不说“严重的强度”。
- “良好”修饰性能和状态：良好的一致性、适应性。

### 5 同一个概念全文一个说法

动笔前列出本文的核心术语，每个概念定一个词，全文不换。常见的混用有：模型、模拟器、仿真器；误差、偏差、残差；试验、实验；标定、校准、辨识。这几组词在不同学科里含义不同，定下来之前先确认本文指的是哪一个。
