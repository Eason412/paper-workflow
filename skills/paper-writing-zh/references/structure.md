# 首尾部件与论文体裁

依据 GB/T 7713.2—2022《学术论文编写规则》和 GB/T 6447—1986《文摘编写规则》。目标刊物的投稿须知、样刊和学校规范与下文不同时，以它们为准。

## 一、题名

- 用一行以内的名词短语点明**研究对象、条件或方法、研究的性质或行为**，中文题名一般不超过 20～25 字。
- 删去不提供信息的头尾空壳，如“基于……的”“关于……的”“……的分析与研究”“……的初步探讨”。综述论文保留“……研究综述”或“……研究进展”以标明体裁。
- 题名范围与正文实际覆盖的条件一致，不把单一工况下的工作夸大成全领域通论（如只做了常温单轴压缩，题名不写“力学性能研究”）。
- 不用非公知的缩略语、商品代号、化学分子式或复杂数学符号。

## 二、引言

引言按漏斗式分三层收拢，篇幅紧凑，直奔问题：

1. **具体工程或科学问题。** 一两句直接切入研究对象面临的实际痛点或失效矛盾，不从宏观政策、行业大背景或教科书常识讲起。
2. **已有工作与研究缺口。** 按问题、方法流派或尺度归类评述前人工作，不按年份或作者记流水账。评述之后明确落到**具体缺口**：哪条机理链尚未打通、哪个耦合工况尚未覆盖、哪类模型的适用边界尚未厘清，不只写一句空泛的“然而上述研究仍存在不足”。
3. **本文切入点与核心工作。** 顺着上面的缺口交代本文从哪里切入、做了哪几步工作、要解决什么。

- 收尾写逻辑脉络，不写成“本文第 1 节介绍了……，第 2 节分析了……，第 3 节总结了……”的章节目录报幕（样刊另有固定习惯除外）。
- 引言一般不设下级标题，不插图、列表或推导编号公式，不与摘要、结论整句重复。

## 三、摘要、关键词与结论
### 1 三处的分工

| | 写给谁 | 回答什么 | 不做什么 |
| --- | --- | --- | --- |
| 摘要 | 没读正文、只看摘要决定读不读的人 | 针对什么问题，怎么做的，得到什么，说明什么 | 不评价，不展开背景，不出现图表公式编号和引用 |
| 结论 | 读完正文的人 | 全文结果合起来说明了什么，在什么条件下成立，还有什么没解决 | 不重复摘要，不拼接各节归纳，不出现正文没有的新结果 |
| 小节归纳 | 正在读这一节的人 | 这一节几段内容的共性 | 不越出本节范围 |

同一个结果在三处的写法不同：摘要报结果本身和关键数字，结论说这个结果的含义和成立条件，小节归纳只在本节内比较。三处的数字必须一致。

### 2 摘要

四件事按顺序写，篇幅向“得到什么”倾斜：

| 要素 | 写什么 |
| --- | --- |
| 针对什么问题 | 一两句，直接说具体问题，不从行业大背景讲起 |
| 怎么做的 | 方法、模型、条件，说出和常规做法的不同点 |
| 得到什么 | 结果或主要判断，占一半左右篇幅，能给数字就给数字和比较对象 |
| 说明什么 | 结果的含义、适用范围，或还没解决的问题 |

- 能脱离正文单独看懂。不写“如图 3 所示”“见式 (2)”“文献 [5]”。
- 写实际内容，不写目录。“首先介绍了……，然后分析了……，最后总结了……”只告诉读者文章有哪几部分，没有告诉他得到了什么。把“分析了 A”换成“A 的分析结果是什么”。
- 只陈述，不评价。不写“具有重要意义”“填补了空白”。
- 不重复题名里已有的信息。缩略语第一次出现给全称。
- 字数和是否分段按刊物或学校的规定。GB/T 7713.2—2022 给的参考是 300～400 字。

**人称。** GB/T 6447 要求不用“本文”“作者”做主语，写成“提出了……”“对……进行了研究”。这种省略主语的句子是摘要的体例，不算缺主语。不少刊物的摘要仍写“本文提出了……”，也有刊物统一写“该文提出……”，如《电工技术学报》。所以先看样刊：样刊用“本文”或“该文”就跟着用，不用就省略，全篇一致。用的时候一段里出现一两次就够，后面用“所提方法”承接。两种情况下都不写“研究围绕……展开”“文中梳理了……”这类为了凑主语造出来的句子。说结果的句子让研究对象做主语，如“误差随转速升高而增大”。

### 3 关键词

3～8 个，选读者会拿来检索的词：研究对象、方法、现象或性能、应用场景各取一两个。用学科里通行的术语，不用临时拼出来的长词组，词与词之间不互相包含。

### 4 结论

GB/T 7713.2—2022 的要求是：结论是对研究结果和论点的提炼与概括，不是摘要或各章节小结的简单重复。

- 每条结论说三件事：得到了什么，在什么条件下成立，说明什么或怎么用。
- 写合起来才能得出的判断：几部分工作共同说明了什么，不同条件下结果为什么不同。逐节各抄一句，就成了小结的拼接。
- 结论以规律、成立条件和适用范围为主。数字只留界定条件和说明关键结果的那几个，不把正文表里的各组数值再报一遍。出现的数字和摘要、正文一致。
- 不引文献，不出现图表公式编号，不出现正文没有论证过的新说法。和前人的比较放在引言和讨论里。
- 不写“取得了重要进展”这类自我评价，价值用结果本身来说明。
- 不足和展望写具体的问题：哪个条件没覆盖，哪个假设需要放宽，哪项验证还没做。“有待进一步深入研究”不提供信息。
- 分条还是成段、要不要总起句，看样刊和模板。

### 5 写完检查

- 把摘要单独拿给没读过正文的人看，他能不能说出这篇文章得到了什么。
- 摘要里有没有只说“进行了研究”而没说结果的句子。
- 把结论和摘要并排看，不能是同一段话的两个版本。
- 把结论和各节归纳并排看，结论的每一条都应当比任何一节的归纳范围更大，或者多了条件和含义。
- 结论的每一条去掉后，全文是不是少了一个判断。不少，就是空话。
- 摘要、结论、正文三处的数字一致。

## 四、研究论文与综述论文的体裁差异

写稿或改稿前先认清体裁，两类论文在下面五处的写法不同：

| 位置 | 原创研究论文（提方法、做试验、跑仿真） | 综述论文（跨文献梳理、对比与评述） |
| --- | --- | --- |
| 题名 | 点明具体对象、所提方法或特定工况 | 点明综述主题范围，以“……研究综述 / 研究进展”收尾 |
| 引言收尾 | 针对前人方法的具体局限，提出本文方法或开展本文试验 | 指出既有综述遗漏的主线或横向对比，交代本文的梳理脉络 |
| 正文引述 | 前人工作集中在引言和对比分析；正文主体写自己的推导、试验与结果 | 全文按机理、工况或模型分类推进；默认以现象和机理做主语（句末标 `[X]`），只在归属特定标定参数、对照分歧结论或专段细剖代表作时点“某某等 `[X]`” |
| 图与表 | 摆自己的试验装置、实测波形、仿真云图与对比误差表 | 用综合机理示意图串联跨尺度过程（自绘图不挂单篇文献号，引原图在图题末标 `[X]`），用通栏汇总表横向拉通多篇文献的工况、指标与局限（表注说明各自基准） |
| 结论与展望 | 提炼本文结果的规律与成立条件；不足只写本文未覆盖的一两点 | 提炼跨研究共性规律与工程选型判据；单列一条具体瓶颈与展望（点明哪几个量化映射、统一法则或耦合试验尚待建立，不写空泛口号） |
