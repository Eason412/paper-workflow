# 图表与公式体例

## 一、图和表

图表负责给出数据和关系，正文负责说从中得到了什么。两边不重复。数据图具体怎么画用 paper-figure。目标刊物另有规定时以它为准。

### 1 图名和表名

名字是一行以内的名词短语。读者不看正文，只看名字和图，就知道画的是什么对象、什么量、什么条件。

| 内容 | 常用形式 | 例 |
| --- | --- | --- |
| 一个量随另一个量变化 | A 随 B 的变化 | 电流误差随转速的变化 |
| 几种条件或方法的比较 | 不同 X 下的 Y；A 与 B 的 Y 对比 | 不同负载下的转矩波形；两种模型的电流误差对比 |
| 结构、原理 | ……结构示意图；……原理图；……控制框图 | 电机模拟器结构示意图 |
| 步骤 | ……流程 | 参数辨识流程 |
| 实物 | ……实验平台；……试件 | 功率级实验平台 |
| 表：给定的量 | ……参数 | 样机主要参数 |
| 表：得到的量 | ……结果；……对比 | 各工况下的误差对比 |

- 不写结论。“所提模型误差更小”是正文里的判断，不是图名。
- 不写成句子，末尾不加句号，不写“关于……的图”。
- 删掉不提供信息的尾巴，如“……的分析与研究”“……结果汇总”。
- 同一类图表用同一种结构。前一张叫“不同转速下的电流波形”，后一张就叫“不同负载下的电流波形”，不改成“负载变化时电流的波形图”。
- 名字说对象和条件，坐标轴说量和单位，两处不重复。
- 分图名只写各分图的区别，如“(a) 500 r/min”“(b) 2000 r/min”，共同的部分放在总图名里。
- 图名在图下方，表名在表上方，都先编号。

### 2 图表之前写什么

用一两句话引出，回答“为什么这里要看这张图表”：它要回答的问题，或者得到它的条件。正文先提到图表，图表再出现。

例：为检验模型在高速段的精度，在 500～2000 r/min 范围内对比了模型输出与实测电流，结果如图 5 所示。

试验条件、参数设置放在这里或更前面，不放到图后的分析里去。

### 3 图表之后写什么

写得到了什么。顺序是四步：看哪一处，得到什么判断，原因是什么，说明了什么。

改前：由表 3 可知，转速为 500、1000、1500、2000 r/min 时，电流误差分别为 1.2%、1.5%、2.1%、4.8%，转矩误差分别为 0.8%、1.1%、1.9%、5.3%。

改后：由表 3 可见，转速不超过 1500 r/min 时，电流误差和转矩误差都在 2.1% 以内，随转速缓慢增大。转速升至 2000 r/min 后，两项误差分别达到 4.8% 和 5.3%，增幅远大于低速段。这说明模型未计入的高频损耗在高速段已经不能忽略。

- 这些内容图表自己已经说了，正文不重复：坐标轴是什么量，哪条线对应哪种方法，表里的每一个数，曲线“先升后降”这类一眼能看到的形状。
- 写初稿时，数字只报支撑判断的那几个：最大值、最小值、拐点、和基线的差；每报一个数，后面要有它说明了什么（改已有稿件时不擅自删数，按 SKILL.md「改稿」归并并列清单确认）。
- 区分两类图：验证原理的波形图，顺着“激励条件—物理原因—响应规律”的因果链写；多方法或多工况的对比图（及多行表），按指标横向归并着比，先把规律一致的归成一组概括趋势，再单独说发生转折或方向相反的那一组，不按分图 (a)、(b)、(c) 或表行从头念到尾。
- 原因必须来自材料或作者已有的分析。材料里没有解释时，只写现象和判断，不替作者编机理。
- 提到图表有三种写法，按这句话的主角选。主角是图表本身，即第一次引出它、交代它画的是什么，用“……如图 X 所示”或“图 X 给出了……”。主角是结果，图表刚在上一句点过名，就直接写判断，不再提图号。主角是结果，但隔了一段再回来说这张图，或者要指给读者看图里的某一处，用“由图 X 可见，”“由图 X(b) 的局部放大可以看出，”起句，后面跟判断。
- “由图 X 可知”本身没有毛病，毛病出在两处：后面跟的是一串数而不是判断；一张图的分析里句句用它起头。
- 句末括号“（图 X）”多见于理科和英文期刊。电工类期刊基本不用，抽查《电工技术学报》七篇论文，“如图 X 所示”73 处，“图 X 为、图 X 给出了”21 处，“由图 X 可知”一类 25 处，句末括号 0 处。样刊用才用。
- 两个自查：把这一段删掉，读者只看图表能不能得到同样的结论，能，说明这段只是在复述；把图表拿掉，只读这一段能不能看懂结论，不能，说明判断没有写出来。
- 正文里没有用来支撑任何判断的图表，删掉或移到附录。

### 4 图里的字

图是用形状、位置和线条表达关系的，字只用来帮读者认出对象。

- 图里留这些：坐标轴的名称和单位、刻度值、图例、分图编号，以及必要的短标注，如区间编号、关键点、指示箭头。
- 这些不放进图里：成句的解释，结论，推导，参数清单，大段的条件说明。它们放到正文里；条目多的放到表里。
- 标注用词或短语，不用句子。能直接标在曲线或部件旁边的，不另加文字框。
- 示意图和框图里，每个框一个名词短语，箭头上只写传递的量。一个框里要写两行以上才能说清，说明这部分该由正文来讲。
- 自查：遮住图里所有的字，只剩图形和坐标，图要表达的关系还看得出来。看不出来，说明这张图是在靠文字表达，需要重画。
- 区间已经用Ⅰ、Ⅱ、Ⅲ或 a、b、c 标出时，图里不再印一套阶段名称，名称放在正文里解释。
- 图例只写对象或条件的名称，不放公式、判据和句子。
- 状态的差别用图形本身画出来。要靠加一行字读者才能看懂的地方，先改图形。
- 图里的术语、符号和正文完全一致。

### 5 表

- 表用来给精确数值和多项指标的对比，趋势用图。同一组数据不同时给图和表。
- 用三线表。单位和百分号写在表头里，如“相对误差/%”，表身只填数字。同一列的有效数字位数一致。
- 性质不同的内容分成两张表，不做大半是空格的合并表。
- 同一来源或同一对象有几行时，左侧相同的单元格合并，不把同样的文字重复几行。
- 表里的文字用词或短语。一个单元格需要一句话才能说清的，放到正文里。
- 全表所有栏目的单位相同时，可把共同单位提取标在表格顶线右上方（看样刊体例）。

### 6 图注、表注与图源标注

图表遵循自明性原则：读者不翻正文，光看“图表 + 题名 + 必要的注”，就能无歧义地读懂对象、量和比较基准。

- **能省则省。** 单位放进坐标轴或表头栏目，曲线和工况身份放进图例或图内短标注。这些已经交代清楚时，不另设“注：……”。
- **三种情况必须加注。** ① 跨文献或跨组数据的比较基准不一致（如综述汇总多篇文献的相对变化率时，表注写明“相对变化率均为各文献相对各自基准组的变化值”）；② 表身或图中有表头容纳不下的特殊记号或空缺（如表内填“—”时，必须注明是“原文献未测试”还是“未发生破坏”）；③ 存在全表/全图共用的前提条件或跨工况适用限制。
- **摆放位置。** 按 GB/T 7713.2—2022 及多数中文核心期刊体例，表注紧贴三线表底线下方左起；分图题（如 `(a) ……`）和图注放在图体下方、总图题上方。目标刊物另有规定时从样刊。
- **综述图源标注。** 直接引用或按单篇文献原样重绘的数据图、试验图，文献编号标在图题末尾（如“图 1 粘结强度与纤维掺量的关系 [31]”）；作者综合多篇文献规律自行提炼绘制的机理示意图，图题末尾不挂单篇文献号，具体数据支撑在正文对应处引用。

## 二、公式、数字与引用

这里只列写正文时最常出错的几项。目标刊物的投稿须知、样刊和学校规范优先。

### 1 公式推导段与“式中”

推导段写清“为什么推、凭什么化简、推出来说明什么”，不写成“将式 (1) 代入式 (2) 可得式 (3)，结合式 (4) 整理得式 (5)”的算式流水账。

- **推导之前**用一句话交代目标：这一步要建立什么关系，或者为什么要改写原方程（例如消除微分项、解耦某两个量）。
- **公式之间**重点写物理条件和近似假设：在哪种工况下忽略了哪一项、为什么可以忽略，或者引入了什么定义。纯代数移项不用逐句文字播报。
- **推导之后**点出式子的物理含义：目标量由哪几部分决定，受哪个参数影响，和后文的控制设计或实验现象有什么关系。
- 物理量的符号用单个斜体字母，需要区分时加下标。不拿英文缩写直接当量符号，例如动态增长系数写成 $K_\mathrm{d}$，不写成 DIF。雷诺数 $Re$ 这类特征数是国标规定的例外。
- 下标是物理量、变量或序号时用斜体，是说明性的缩写或文字时用正体；常见坐标轴下标（如 $d, q, \alpha, \beta$）的正斜体跟从样刊或全文统一。单位符号用正体。
- 公式之后用“式中”逐项说明符号，顺序和公式里出现的顺序一致。每项写“符号为名称，单位”，没有单位的量不写单位，各项之间用分号，最后用句号。“式中”后面用冒号还是逗号、常见量写不写单位，看样刊，例如《电工技术学报》写“式中，”。
- 等号左边的量、定义式里出现的子符号、特殊运算符都要说明。前文已经说明过的符号不重复。
- “式中”只做名称和单位的说明。取值范围、物理含义、适用条件放在后面的正文句子里。
- 公式两边的量纲要对得上，各量的单位要互相匹配。

### 2 数字、单位与数值比较

- 数值和单位符号之间空一格，如 25 mm、0.5 mm/min。百分号和角度的度分秒不空格。
- 数值范围用“～”，两端都带单位或百分号时不省前一个：20%～30%，不写 20～30%；3×10³～5×10³，不写 3～5×10³。
- 同一组比较的数据保留相同的有效数字。单位用法定计量单位，全文统一。
- **百分数与百分点区分。** 本身已是百分数的指标（如误差、效率、掺量）作差值比较时用“百分点”，作相对比例变化时才用“%”。例如误差由 5.0% 降到 2.0%，写“降低了 3.0 个百分点”或“降低了 60%”，不写“降低了 3.0%”。
- **倍数只增不减。** 增加可写“提高了 $N$ 倍”或“提高至原来的 $(N+1)$ 倍”；减少不能写“降低了 2 倍”“缩小了 3 倍”，改用百分数或分数（“降低了 50%”或“降至原来的 1/3”）。
- **数量级按十的幂次用。** “提高了一个数量级”指约为原来的 10 倍，不当作表示“很多”的夸张修辞。

### 3 引用

- 引用编号跟在被引内容之后、句号之前。改稿时编号跟着它支撑的那句话走，不能句子挪走了而编号留在原处。
- 调整段落或图表的顺序后，按出现先后编号的引用要重新检查，编号仍应按第一次出现的顺序连着排。
- 摘要和结论里一般不引文献。

### 4 缩略语

- 缩略语在摘要和正文里各自第一次出现时给全称，之后只用缩写，不再反复夹注。
- 全文只出现一两次的概念直接写全称，不设缩略语。
