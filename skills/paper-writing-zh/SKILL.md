# 中文论文写作与改稿

用户当次的要求最优先，其次是目标刊物或学校的模板与样刊，最后才是本文件。动笔和改稿前先读 [范文](references/examples.md)，句子的长短、转折词和标点向它靠。目标刊物的样刊另有体例时，体例跟样刊。

## 句子

每个句子按下面四步检查，前一步过了再看后一步。判断方法、例句和搭配表见 [句子与搭配](references/sentence.md)。

1. **一句一个判断。** 条件和原因可以跟在判断后面，第二个判断另起一句。拆句只在两个判断之间拆，不在一个判断的中间拆。拆完以后，后半句要靠“这样才能”“这种”“该”才立得住，说明拆错了，合回去。
2. **主干成立。** 去掉所有修饰语，只留“谁、怎么样、什么”，读这个短句：主语在不在，是不是被“通过……”“在……下”这类介词短语吞掉了；主语和谓语、动词和宾语配不配。
3. **修饰语挂得住。** 每个定语、状语和它修饰的词单独配一遍。定语长到读者迟迟等不到中心词，或者带两个以上“的”，挪到后面另成分句。
4. **读得下来。** 每个逗号都落在能换气的地方，一句之内换主语不超过两次，读到句末还记得主语是谁。读不下来时，回到第 1 步看它是不是装了两个判断，再看主语和谓语之间是不是隔了很长的修饰语。

句子多长不设要求，长短是前面四步的结果，不是目标。不按字数去拆句或凑句：一个判断带着必要条件的长句可以留，一个独立的判断只有十来个字也可以留。

读着憋气的句子多半是三种结构，拆开：“某某实验表明，”后面拖一长串判断；冒号后面跟一串分号；“虽然、但、然而、却”连环转折。

读着碎的句子多半也是三种结构，并回上一句：把上一句的目的或结果拆成“这样才能……”；连续用“这种”“该”起句；把同一个对象的优点和局限拆成“……。但它……。”。

**节奏。** 同一条因果链上的几个短句并成一句，独立的判断留成短句，长短自然就错开了。短句适合下结论、点转折，较长的句子适合讲机理和条件。一段里的句子都是一个长度、一个句式，读起来就没有起伏。

**标点。** 一个判断说完就用句号收住。列举的每一项自己能成句时用句号分开，不用冒号加分号，也不用分号把几篇文献连成一句。分号只用于三处：内部已有逗号的成对并列分句、短项列举、“式中”说明。冒号一直管到句号，一句不套两个冒号。用对了的冒号和分号不动；拿不准时换成句号试读，正反例见 [句子与搭配](references/sentence.md) 第 6 节。

## 主谓宾搭配

- 换了陈述对象就把新主语写出来；对象没换可以承前省略，不必句句重复，也不为凑主语硬加“研究”“文中”。
- 动词和宾语、形容词和名词按名词的性质配：分高低的量用“提高、降低”，分大小的用“增大、减小”，分强弱的用“增强、削弱”，分长短的用“延长、缩短”。完整的表在 [句子与搭配](references/sentence.md) 的第二部分。
- “A 是 B 的前提、基础、关键”里，A 和 B 是同一类东西：动作对动作，性质对性质。
- 一个主语带几个谓语、一个动词带几个宾语、一个形容词修饰几个名词时，每一对单独读一遍。并列的几项用同一种结构。
- 分类词贴合对象性质，不拿“层面、维度、视角”当万能筐，也不删掉介词拿范围词硬当主语（如“细观层面揭示了……”）。
- 主语很长、谓语只有几个字的句子，把主语里的修饰语挪到后面。

## 段落

- 一段只有一个主旨，由段首句说出来。读者只读段首句，就知道这一段讲什么；把各段的首句连起来读，能看出这一节的走向。
- 分析结果和评述文献时，段首句的主语是研究对象，不是“图 8”“文献 [3]”“本文”（首次引出图表交代实验条件时用“图 X 为……”“图 X 给出了……”除外）。段首句写什么，看这一段在做什么：分析结果，写判断本身；引出图表，写为什么看它、在什么条件下得到；评述文献，写这类方法要解决的问题或怎么分类；讲方法和推导，写这一步要得到什么。
- 承接上文的话做段首句的前半句，不单独成句。背景只有一句时并到上一段末尾。不用“此外”“另外”“同时”起段。
- 写一节或连着几段时，先把各段的首句列出来，连起来读通了再展开，交付时附上这份段首句清单。改稿也先列出原稿各段的首句看走向，再动句子。
- 默认直说：段首句给出判断，后面给证据、原因和条件。
- 三种情况改成先摆现象、再给判断：结果不利或不合预期；判断出人意料，读者要先看证据；评价别人的工作。这时克制的是语气，不是结论：条件、数字和原因照实写，最后把它落成适用范围或改进方向，不能只摆现象让读者自己猜。
- 论断的强弱跟着证据走：直接测到的用“为”“达到”，数据支持的用“表明”，有依据的推断用“主要原因是”，没有验证的用“可能”“推测”。
- 句子之间靠内容衔接：下一句从上一句末尾刚提到的东西说起，新信息放在句末。
- 连接词只在逻辑关系需要它时用。转折、让步和条件必须写出来；顺承和并列通常不用；动词已经表达了因果就不再加“因此”。前后两句没有真正相反的意思就不用“然而”“但”“却”，一段里不连着几句用转折词起头。“综上”只在真的归纳了前面几点时用。
- 引述文献默认让现象、机理或方法做主语，编号放句末，不连排三句以上“某某等 [X] 发现……”；只在归属特定标定参数、对照分歧结论或专段细剖某项工作时点作者名。正文可回指前文，不提前写“这也是后文 X.X 节的依据”这类预告。
- 生造的伪深奥词换回常规说法；不可替代的硬核术语首次出场时用半句话铺垫物理过程或作用（见 [句子与搭配](references/sentence.md) 第 8 节），之后全文一词到底，不换同义词。项目里有术语表或符号表时先读再用。

例段、段与段的衔接、小节标题与文献引述见 [段落与衔接](references/paragraph.md)。

## 图和表

- **图名表名**是一行以内的名词短语，写清对象、量和条件，如“不同转速下的电流误差”。不写结论，不写成句子，同类图表用同一种结构。
- **图表之前**用一句话引出：这张图表回答什么问题，或者在什么条件下得到。正文先提到，图表后出现。
- **提到图表的写法**跟目标刊物。电工类期刊的做法是：每张图表用“如图 X 所示”或“图 X 给出了……”点名一次，之后的分析直接写判断；隔了一段再回来说它，或者要指给读者看图里的某一处，用“由图 X 可见，”起句，后面跟判断，不跟一串数。句末括号“（图 X）”这类期刊不用，样刊用才用。
- **图表之后**写得到了什么，不把图表再念一遍。顺序是：看哪一处，得到什么判断，原因是什么，说明了什么。原理验证图顺着“激励或条件—物理原因—响应规律”讲；多方法或多工况对比图按指标横向归并着比，不按分图 (a)、(b)、(c) 或表行挨个念。写初稿时数字只报支撑判断的那几个（极值、拐点、与基线的差）；改稿时不擅自删数，见「改稿」。
- **图里少写字。** 图里只留坐标轴名称和单位、图例、分图编号和必要的短标注。成句的解释、结论和参数清单放到正文或表里。遮住图里所有的字，图要表达的关系应当还看得出来。

细则和例子，以及图注表注、公式推导段、“式中”说明、数值比较（百分点与倍数）、引用和缩略语，见 [图表与公式体例](references/figure_table.md)。

## 首尾部件与体裁

题名点明研究对象、条件或方法与性质，删去“基于……的分析与研究”类空壳。引言按“具体问题—已有工作及具体缺口—本文切入点”收拢，不写章节目录报幕。摘要说清问题、做法、结果和含义；结论提炼全文规律、成立条件与具体瓶颈，不重抄摘要或拼接各节小结；两者都不引文献、不带图表公式编号。题名、引言、摘要、关键词、结论的细则，以及研究论文与综述论文的体裁切换，见 [首尾部件与论文体裁](references/structure.md)。

## 改稿

- 先看上下文再动笔：改某一段或写某一段前，先读它的上一段、下一段以及所在小节的标题，看清承接关系、术语叫法和主语指代，不孤立改单段。
- 从大到小改：先段落的主旨和顺序，再句子，最后词语和标点。一次改一个自然段，核对完再改下一个。
- 只改表达。数字、单位、符号、引用编号、限定条件、原因句、比较的方向和论断的强弱原样保留。把句子改顺时最容易顺手删掉“因为什么”，删了它，结论就没有依据。
- 不补原文和材料里没有的数据、机理和文献。可以补的是结构：分类的总起句和句间的过渡。如果原稿前句只写了做法、本段后文或相邻段落已经点出了该方法的名称，可以把后文已有的名称提到前句总起，补齐指代断层，这不算新增内容。
- 学科里通行的说法不为了对上搭配表去换词，只改确实配不上的。
- 改完把改后稿里的名词短语逐个对回原文，原文没有的修饰词删掉。把“扰动”写成“参数扰动”，意思就比原文窄了。
- 自己补的总起句和过渡句同样按「句子」的四步检查，补的句子最容易带出“进行了改进”这类空话。
- 需要结合实际判断、拿不准的地方不硬改，正文照留或先归并，交付时附一份简短的「待作者确认」清单：① 图表后疑似只复述图表、可删减的冗余数据（正文先提判断并归并保留，不自己删）；② 论证中缺失的原因、近似条件或适用边界（不替作者编）；③ 拿不准是语病还是课题组习惯的说法；④ 原稿自身前后的口径矛盾（如前说“不受影响”、后说“影响较小”，不替作者统一）。
- 改完运行 `uv run scripts/compare_facts.py 旧稿 新稿`，核对消失和新增的数字、引用、符号、标点增减、倍数病句与中英摘要数字差异。稿件含英文题名、Abstract、Keywords 或双语图表题时，同步核对中英文的数据、符号和缩略语一致。原因句、条件和数字有没有安到别的对象上，脚本查不出，要逐句对照原文。
- 只让指出问题时，逐条写“原句、毛病属于哪一类、怎么改”，不泛泛地说“建议提高可读性”。
